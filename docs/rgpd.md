# Privacidad y RGPD

- En la cadena solo se guardan direcciones de billetera y hashes de documentos.
- Nunca se guardan nombres, DNI, notas ni documentos en la cadena.
- Un hash puede seguir siendo dato personal si el documento es fácil de adivinar. Se añade un valor aleatorio ("salt") antes de calcularlo.
- Lo que se escribe en la cadena es público y no se puede borrar, lo cual choca con el derecho de supresión. Por eso los documentos reales se guardan fuera de la cadena.
- Este documento no es asesoramiento legal. Un uso real requeriría consultar a un profesional.
